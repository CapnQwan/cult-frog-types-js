Contributing

This repository contains types used across the project ecosystem.

Contributions should preserve the package's existing design principles, documented invariants, and public API unless a change intentionally modifies them.

Development

Install dependencies:

pnpm install

Run the test suite:

pnpm test

Run tests in watch mode:

pnpm test --watch

Build the package:

pnpm build

Run type checking:

pnpm typecheck

Run formatting and linting:

pnpm check
